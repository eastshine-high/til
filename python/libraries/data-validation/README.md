# Python - Data Validation

- 데이터 검증은 외부에서 들어온 데이터가 **기대한 형식과 규칙을 따르는지 확인**하는 작업이다.
- API 요청, 설정 파일, 외부 API 응답처럼 형식을 보장할 수 없는 데이터를 프로그램 안으로 들여올 때 필요하다.
- 파이썬은 동적 타입 언어라서 타입 힌트를 적어도 런타임에는 검사하지 않는다. 그래서 실제 검증은 별도의 라이브러리가 맡는다.
